Glass controls

The slider thumb and the segmented control from Apple's Adopting Liquid Glass page, rebuilt from measurements of its two demo videos. Press, drag and release them. The lens refraction is an SVG displacement filter (verified in Chromium; other engines get the lens without the bend).

Slider

Opaque pill at rest → glass lens on press (2.15× area, refracts the track), stretches with the thumb's acceleration, shrinks on release.

value 0.58

Segmented control

Selected pill grows into a lens taller than the track, magnifies both labels 1.15× (black selected-state copy), slides to the tapped segment and shrinks with an under-damped spring.

For You

Use

<link rel="stylesheet" href="tokens/apple-glass-controls.css">
<script src="tokens/apple-glass-controls.global.js"></script>
<script>
  const slider = GlassControls.slider(document.getElementById("slider"), { value: .58, onInput: v => {} });
  const seg = GlassControls.segmented(document.getElementById("seg"), { items: ["For You", "Library"], onChange: i => {} });
</script>

Sizes are CSS px at the video's own scale (video px ÷ 2); pass scale for other sizes. Numbers: tokens/apple-glass-controls.json; write-up: references/liquid-glass/controls-motion.md.
